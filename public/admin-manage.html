Скачайте согласованную копию базы данных. Файл создаётся командой VACUUM INTO и не требует остановки сервера.

Скачать резервную копию

Восстановление базы данных

  1. Остановите сервер.
  2. Выполните команду npm run db:restore -- путь\к\файлу.db.
  3. Запустите сервер командой npm start.

Скрипт восстановления создаёт резервную копию текущей базы, проверяет целостность и только затем заменяет файл.
